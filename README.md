# LeoneGuard (TOS Compliant) Stats
Public, aggregate-only stats for LeoneGuard (no names, IDs or message text). `stats.json` is auto-updated by the server (scripts/push-stats.sh, which only writes stats.json); the page (index.html + assets/) is static and is never regenerated by the cron.
